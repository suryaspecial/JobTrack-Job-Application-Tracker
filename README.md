# JobTrack – Job Application Tracker

JobTrack is a responsive job application tracking dashboard designed to help users organize and monitor their job search in one place.

The project allows users to add, edit, delete, search, and filter job applications while keeping track of important application statistics. Application data is stored using the browser's Local Storage, so the data remains available after refreshing the page.

## 🚀 Live Demo

https://suryaspecial.github.io/JobTrack-Job-Application-Tracker/

## 📌 Features

- Add new job applications
- Edit existing applications
- Delete applications with confirmation
- Search applications by company or job title
- Filter applications by status
- Track total applications
- Track applied applications
- Track interviews
- Track selected applications
- Persistent data using Local Storage
- Responsive dashboard design
- Light and dark theme
- Interactive status badges
- Responsive navigation
- Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Bootstrap Icons
- Local Storage API
